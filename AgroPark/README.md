# AgroPark Project

AgroPark is a smart agro e-commerce platform designed to connect farmers, suppliers, and customers in a seamless marketplace for quality agricultural products. This project aims to empower local farmers and agri-suppliers by providing an easy-to-use platform for buying and selling agricultural goods.

## Project Structure

```
AgroPark
├── index.php          # Homepage of the application
├── contact.php        # Contact us page with a form for user inquiries
├── products.php       # Displays available products for purchase
├── cart.php           # Manages shopping cart functionality
├── login.php          # Handles user login functionality
├── db_connect.php     # Establishes connection to the database
├── uploads            # Directory for storing uploaded files
├── assets             # Directory for static assets
│   ├── css           # Contains stylesheets
│   │   └── style.css  # Main stylesheet for the application
│   └── js            # Contains JavaScript files
│       └── main.js    # Main JavaScript file for the application
└── README.md          # Documentation for the project
```

## Features

- **User-Friendly Interface**: Easy navigation and access to products.
- **Contact Us Form**: Users can reach out for inquiries or support.
- **Product Display**: Showcase of available agricultural products.
- **Shopping Cart**: Functionality to manage selected products for purchase.
- **User Authentication**: Secure login for users.

## Getting Started

1. Clone the repository to your local machine.
2. Ensure you have a local server environment (e.g., XAMPP) set up.
3. Import the database schema from `db_connect.php` to your database.
4. Access the application via your web browser at `http://localhost/AgroPark/index.php`.
