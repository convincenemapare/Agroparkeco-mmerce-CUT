# AgroPark — Smart Agro E-Commerce Platform

A full-stack agricultural e-commerce web application connecting 
farmers, suppliers and customers in Zimbabwe's agricultural market.

## Features
- User registration & secure authentication
- Dynamic product catalogue with search & category filtering  
- Shopping cart & checkout system
- Admin dashboard — product & order management
- Customer order tracking
- Report export system

## 🛠️ Technologies Used
- **Backend:** PHP, MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL via XAMPP / phpMyAdmin
- **Tools:** VS Code, Git, GitHub

## ⚙️ Setup Instructions
1. Clone this repo
2. Place folder in `C:\xampp\htdocs\agropark`
3. Open phpMyAdmin → create database named `agropark`
4. Import `agropark.sql`
5. Run via `http://localhost/agropark/index.php`
